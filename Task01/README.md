# Описание файлов данных

В папке `Task01` находятся следующие файлы:

## ratings.csv
Оценки пользователей фильмам.
Колонки: `userId`, `movieId`, `rating`, `timestamp`.
Разделитель: запятая.

## movies.csv
Информация о фильмах.
Колонки: `movieId`, `title`, `genres`.
Разделитель: запятая.

## tags.csv
Теги, присвоенные пользователями фильмам.
Колонки: `userId`, `movieId`, `tag`, `timestamp`.
Разделитель: запятая.

## users.txt
Информация о пользователях.
Колонки: `userId`, `gender`, `age`, `occupation`, `zip`.
Разделитель: вертикальная черта (`|`).

## genres.txt
Список жанров фильмов. По одному жанру на строку.

## occupation.txt
Список профессий пользователей. По одной профессии на строку.
